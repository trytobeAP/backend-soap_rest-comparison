# 🛡️ Backend: SOAP vs REST Comparison

Серверная часть курсовой работы. Реализует два веб-сервиса (SOAP и REST) для доступа к единой базе данных студентов.
Написано на **Node.js + TypeScript + Express**.

## 🚀 Как запустить с нуля

### 1. Установка Node.js

Если у вас не установлен Node.js, скачайте и установите версию **LTS** с официального сайта:
👉 [Скачать Node.js](https://nodejs.org/)

### 2. Установка зависимостей

Откройте терминал в папке проекта и выполните команду:

```bash
npm install
```

Для запуска в режиме разработки выполните:

```bash
npm run serve
```

### После запуска сервер будет доступен по адресу: `http://localhost:8000`

---

## 📂 Что внутри?

- **REST API:** Доступен по префиксу `/api`.
  - `GET /api/students` — Получить всех студентов (JSON).
  - `POST /api/students` — Создать студента.
  - `POST /api/admin/seed` — Генерация тестовых данных (1k, 5k, 20k записей).
- **SOAP Service:** Доступен по префиксу `/soap`.
  - **WSDL:** `http://localhost:8000/soap?wsdl` — Описание сервиса (XML).
- **Database:** Используется **SQLite**. Файл `students.db` создается автоматически в корне проекта при первом запуске.

## 🛠 Стек технологий

- **Node.js & Express** — веб-сервер.
- **soap** — библиотека для реализации SOAP-сервиса.
- **sqlite3** — база данных.
- **TypeScript** — язык программирования.
